1. Instalacia django do pythonu:
	pip install django
	pip list
asgiref  3.11.1
Django   6.0.6
pip      26.1.2
sqlparse 0.5.5
tzdata   2026.2

2. Vytvorenie projektu: 
	django-admin startproject nazov_projektu .

3. Nastavenie slovenciny pre projekt (nazov_projektu/pokus/settings.py):
	LANGUAGE_CODE = 'sk'
	TIME_ZONE = 'Europe\Bratislava'
4. Spustenie vývojového servera
	python.exe .\manage.py runserver
	bezi na adrese 127.0.0.1:8000

5. Vytvorenie aplikacie
	python.exe .\manage.py startapp nazov_aplikacie

6. Registracia aplikacie do projektu(nazov_projektu/pokus/settings.py)
	INSTALLED_APPS = [
    	'django.contrib.admin',
    	'django.contrib.auth',
    	'django.contrib.contenttypes',
    	'django.contrib.sessions',
    	'django.contrib.messages',
    	'django.contrib.staticfiles',
    	'nazov_aplikacie',
	]

8. vytvorenie url pattern
8.1 nazov_projektu/pokus/urls.py


	from django.contrib import admin
	from django.urls import path, include

	urlpatterns = [
    	path('admin/', admin.site.urls),
    	path('nazov_aplikacie/', include('skola.urls')),
    
	]

8.2 Vytvorit subor urls.py v priecinku aplikacie
	from django.urls import path
	from . import views

	urlpatterns = [
		path('',  views.index, name='index'), #views.index je nazov funkcie vo views
	]
